# AWS Cloudscape — thin edition

A trimmed copy of [samples/cloudscape](../../samples/cloudscape/SOURCE.md), for quick checks on a small but realistic system. Made by `node scripts/thin.mjs`; not edited by hand.

- Kept: Text, background and border colors for the body, layout, containers, buttons, inputs, links and status; type sizes, weights and line heights; static spacing and the main radii; the alert and header contexts. No chart colors.
- Also kept: every token those point at, so no reference is broken by the trimming.
- Tokens are as published: same names, values, types and descriptions. Only whole tokens, files and themes were left out.
- 540 tokens in 1 files.
