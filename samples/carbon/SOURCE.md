# IBM Carbon

- Source: npm `@carbon/themes` (`tokens/themes/`) and `@carbon/colors` (`tokens/colors.tokens.json`) — https://github.com/carbon-design-system/carbon
- Version: @carbon/themes 11.85.0, @carbon/colors 11.62.0
- License: Apache-2.0 (see `LICENSE` in this folder)
- Downloaded: 2026-11-12

Two of Carbon's four themes are kept, flattened into this folder so the whole set loads in one drag:

- `*.light.tokens.json`: the White theme (`tokens/themes/white/`)
- `*.dark.tokens.json`: the Gray 100 theme (`tokens/themes/g100/`)
- `colors.tokens.json`: the base colors both themes point to

File contents are unmodified; only the names changed. Left out: the g10 and g90 themes.
