DTsanity

DTsanityFiles

Validate and refine your design tokens system

Checks the DTCG format with one-click fixes, plus contrast (WCAG 2.2, APCA) and color blindness for every pair. Reads Tokens Studio and Style Dictionary too.

Privacy

Your tokens never leave this browser tab.

Files are read and processed on this page only. Their names, values and structure are never uploaded, stored or sent anywhere.

The only network request this page makes is to a URL you type in, and only when you click Load.

Check it yourself

Open your browser's developer tools, go to the Network tab, and load a file. Nothing is sent. You can also turn off Wi-Fi after the page loads; everything keeps working.

Full isolation

Clone the repository and run the strict build (npm run build:strict), which works offline from a local file.
